# 06. Copy review: neutrality and accuracy

Reviewed 17 November 2026 against the local copies of the report, the annex and
the data tables, and against the local route (`localhost:3100/uk/milburn-review`,
default measure "The report's benefit changes", 2029-30). Nothing in the code or
data was changed; this note is the only file written.

Verdict: the report's own figures are quoted correctly, and published figures are
labelled as published everywhere checked. No advocacy was found in the strings
read (see "Not checked"). The problems are (a) two of the four report measures
have no results on the local route, though Methodology counts them, (b) wording
left over from before the report runs were added, mostly in Methodology and
`milburn_measures.json`, (c) PolicyEngine figures for 2027-28 in the benchmarks
beside 2029-30 figures for the same measure elsewhere, and (d) "upper bound"
used for a saving that the page's own Return to work run exceeds.
